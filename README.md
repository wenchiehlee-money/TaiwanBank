# 🇹🇼 TaiwanBank: 台股大盤頭部成交量與貨幣供給額 (M1B) 比重分析

此專案旨在量化分析台灣股市（集中市場與店頭市場）在歷史波段高點（頭部）的資金熱度。透過分析最大單日成交量佔中央銀行 M1B 貨幣供給額的比重，提供研判大盤是否進入「泡沫過熱期」與「長線頭部」的量化評估工具。

---

## 🧭 專案核心指標

### 1. 狹義貨幣供給額 (M1B)
M1B（包括通貨淨額、支票存款及活期存款）被視為股市的資金活水。當民間資金高度湧入股市時，成交量佔 M1B 的比例會顯著飆升。

### 2. 最大單日成交量
代表在某一波段高點（頭部）期間，市場投機情緒最高昂、資金流動速度最快的那一天所產生的交易金額（億元）。

### 3. 「市場小計」的總經分析價值
*   **計算方式**：上市（TWSE）最大日成交量 $+$ 上櫃（TPEX）最大日成交量。
*   **資金排擠效應**：資金常在上市大盤股與上櫃中小型股之間相互流動。僅看單一市場（例如上市）容易因為上櫃搶走資金而低估投機狂熱程度。**「市場小計」加總能更客觀地反映整個證券市場吸納資金的總胃口。**
*   **終極過熱指標（頭部警戒線）**：
    *   **歷史大頭部**（比重高達 **8% ~ 11%**）：如 1990 年（11.00%）、1997 年（8.79%）、2000 年（8.44%）。此時全市場的投機狂熱消耗了大量的社會流動性資金，一旦資金動能耗盡，股市極易見頂崩盤。
    *   **中繼波段頭部**（比重介於 **1% ~ 3%**）：如 2011 年（1.40%）、2018 年（1.27%），通常代表由基本面主導的溫和高點。
    *   **當前熱度（2026/04-05 波段）**：市場小計比重達 **6.49%**。顯示熱度已顯著高於近年的中繼高點，但仍低於歷史大泡沫的極端門檻。

## 🛠️ 主要檔案說明

*   [m1b_peak_analysis.py](m1b_peak_analysis.py)：分析核心腳本。自動從央行 OpenData 下載最新的 M1B 日平均，並串接證交所 (TWSE) FMTQIK 與櫃買中心 (TPEX) st41 API，動態抓取歷史波段高點的成交量並計算佔比。
*   [m1b_peak_result.csv](m1b_peak_result.csv)：由分析腳本產出的數據檔案。包含自 1989 年至今，所有大漲與中漲波段的上市、上櫃及「市場小計」數據。
*   [m1b_peak_analysis_report.md](m1b_peak_analysis_report.md)：詳細的分析報告，包含格式化數據表、歷史數據比對、核心發現與潛在天量推估。
*   [m1b_analysis.py](m1b_analysis.py)：基礎 M1B 走勢與大盤指數關聯分析腳本。

## 🚀 快速開始

### 1. 執行分析
確保已安裝 pandas、requests。在專案根目錄下執行：
```bash
python m1b_peak_analysis.py
```
> *備註：若在 Windows 環境下，本腳本已自動處理 Standard Output 編碼以避免中文字元 UnicodeEncodeError。*

### 2. 使用 MCP (Model Context Protocol) 驗證數據
本專案配置有專屬的 `taiwan-stock` MCP 伺服器，位於相對路徑 `../mcp-cli/` 中，您可以透過它逐一核對各日期的收盤點位與成交量：
```bash
# 查詢特定日期的市場數據
mcp-cli -c ../mcp-cli/mcp_servers.json call taiwan-stock get_market_data '{"date": "2026.05.06", "market": "上市"}'
```
